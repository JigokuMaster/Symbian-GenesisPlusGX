# GenesisPlusGX for Symbian 9.x

Genesis Plus GX is an open-source Sega 8/16 bit emulator focused on accuracy and portability.

this port for Symbian is built using SDL 1.2.14 Library. for now it supports only Sega master system/Game Gear ROMs.

---


## Requirements & Compatibility
- **Target OS:** Symbian OS v9.x (S60v3 devices)
- 30MB+ of free RAM.

## Installation
1. Download the latest `.sis` / `.sisx` package from the Releases section.

2. P.I.P.S v1.7

## Usage

1. Place game ROMs, e.g, in `E:\Data\GenesisPlusGX` or `C:\Data\GenesisPlusGX`


2. Configure controls from input settings.

Note: GREEN/CALL key is reserved for toggling mouse mode used for emulating light gun required by some games like "Rescue Mission".
