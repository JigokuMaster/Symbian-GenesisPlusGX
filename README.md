# GenesisPlusGX for Symbian 9.x

Genesis Plus GX is an open-source Sega 8/16 bit emulator focused on accuracy and portability.

This port for Symbian is built using SDL 1.2.14 Library.

---


## Requirements & Installation
- **Target OS:** Symbian OS v9.x (S60v3 devices)
- 30MB+ of free RAM.
- P.I.P.S v1.7
- Download the latest .sis / .sisx package from the Releases section.



## Usage

1. Place game ROMs, e.g, in E:\Data\GenesisPlusGX or C:\Data\GenesisPlusGX 
2. Configure audio (Latency fix) open Audio settings select "system queue" in stream mode.

Note: GREEN/CALL key is reserved for toggling mouse mode used for emulating light gun required by some games like "Rescue Mission".

# Supported ROMs

GenesisPlusGX will emulate the following systems:

* SEGA SG-1000 / SG-1000 II
* SEGA SC-3000
* SEGA Mark III
* SEGA Master System J, 1 & 2
* SEGA Game Gear
* Othello Multivision
